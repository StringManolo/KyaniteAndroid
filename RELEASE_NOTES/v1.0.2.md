## 🇺🇸 English {#english}

### What's new

- **Updated internal Kyanite version:** The Linux environment bundled with KyaniteAndroid has been updated to Kyanite v0.2.1.
- **Faster shell startup:** Reduced shell initialization overhead by moving missing-command helper generation to the rootfs build process.
- **Expanded command coverage:** Significantly increased the database of missing-command hints, covering hundreds of commonly used Linux utilities.
- **Debian package integration:** Missing commands now provide installation hints using Debian package names and the `kpkg add` command.
- **Improved command detection:** Better recognition of existing executables and Brush builtins, preventing unnecessary command hints and conflicts.

## 🇪🇸 Español {#español}

### Novedades

- **Actualización de la versión interna de Kyanite:** El entorno Linux incluido en KyaniteAndroid se ha actualizado a Kyanite v0.2.1.
- **Inicio más rápido de la shell:** Se ha reducido el tiempo de inicialización trasladando la generación de ayudas para comandos inexistentes al proceso de construcción del rootfs.
- **Mayor cobertura de comandos:** Se ha ampliado considerablemente la base de datos de sugerencias de comandos, incluyendo cientos de utilidades Linux habituales.
- **Integración con paquetes Debian:** Los comandos inexistentes ahora muestran sugerencias de instalación utilizando nombres de paquetes Debian y el comando `kpkg add`.
- **Detección de comandos mejorada:** Mejor reconocimiento de ejecutables existentes y comandos internos de Brush, evitando sugerencias innecesarias y conflictos.

## 🇷🇺 Русский {#русский}

### Что нового

- **Обновление внутренней версии Kyanite:** Среда Linux, поставляемая вместе с KyaniteAndroid, обновлена до Kyanite v0.2.1.
- **Более быстрая загрузка оболочки:** Снижены затраты времени на инициализацию благодаря переносу генерации подсказок для отсутствующих команд на этап сборки rootfs.
- **Расширенная поддержка команд:** Значительно увеличена база подсказок для отсутствующих команд, охватывающая сотни распространённых утилит Linux.
- **Интеграция с пакетами Debian:** Для отсутствующих команд теперь отображаются подсказки по установке с использованием имён пакетов Debian и команды `kpkg add`.
- **Улучшенное обнаружение команд:** Улучшено распознавание существующих исполняемых файлов и встроенных команд Brush, что предотвращает ненужные подсказки и конфликты.

## 🇨🇳 简体中文 {#简体中文}

### 更新内容

- **更新 Kyanite 内部版本：** KyaniteAndroid 内置的 Linux 环境已升级至 Kyanite v0.2.1。
- **更快的 Shell 启动速度：** 将缺失命令辅助函数的生成过程移至 rootfs 构建阶段，减少了 Shell 初始化开销。
- **扩展命令支持范围：** 大幅扩充了缺失命令提示数据库，涵盖数百种常用 Linux 工具。
- **Debian 软件包集成：** 对于缺失的命令，现在会使用 Debian 软件包名称和 `kpkg add` 命令提供安装提示。
- **改进命令检测：** 更准确地识别已有的可执行文件和 Brush 内置命令，避免不必要的提示和命令冲突。
