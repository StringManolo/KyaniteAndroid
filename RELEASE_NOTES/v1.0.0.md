**Kyanite v1.0.0**

Kyanite is a lightweight Linux environment for Android that runs a full
Linux userspace **without root**, with its own package manager and init system.

### First stable release

- Signed with a release key (not a debug key).
- No root required. Works on stock Android.
- **Minimum Android version: 7.0 (Nougat, API 24).**

### What's included

- Linux userspace running on Android via proot.
- Custom Kyanite root filesystem.
- Custom package manager (`kpkg`).
- Kyanite Init for environment initialization.
- ARM64 kernel support using an Alpine Linux virtual kernel.
- VirtIO support for virtualized environments.
- Lightweight command-line environment.

### Installation

1. Download `Kyanite.apk` below.
2. Install it on your Android device (allow installs from unknown sources).
3. Open Kyanite.

### Downloads

- **`Kyanite.apk`** — arm64-v8a (recommended for most devices).
- **`kyanite_v7.apk`** — armeabi-v7a, for older 32-bit devices only.

### Notes

- If you had a previous build installed, uninstall it first: the release
  key is new, so Android won't allow an in-place update over a debug build.
